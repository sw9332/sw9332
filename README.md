# Seon-Wook Kim

I am a university student majoring in Game Software.

I primarily develop games using Unity, with a focus on game client programming in C#. Through various team projects, I have gained practical experience in game design, programming, team collaboration, and project management.

Alongside game development, I have been studying graphics programming with DirectX. I have explored how graphics frameworks are structured, as well as core concepts such as the rendering pipeline, lighting, and animation. I have also applied what I learned by developing a game using DirectX, gaining practical experience in low-level graphics programming.
